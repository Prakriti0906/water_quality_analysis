# water_quality_analysis
In the data given, the various features were accounted for, which are responsible for accounting for the post monsoon **EWQI** (Entropy weighted water quality index of water)
https://github.com/Prakriti0906/water_quality_analysis/blob/main/HyperparameterTuning/Autosampler/Optuna_autosampler_WaterQualtiy%20(1).ipynb:
This link is used to apply different combinations of pruners to obtain the BEST fitting model and pruner combination for the autosampler


https://github.com/Prakriti0906/water_quality_analysis/blob/main/Conformal_Prediction/Conformal_Prediction/Conformal_Predictions(MAPIE%2CPUNCC)_water_quality%20(1)%20(1).ipynb: 
This link is used to increase the reliability of the predicted value by increasing the prediction percentage using methods such as **Conformal Prediction**,**PUNCC**, and **MAPIE**


https://github.com/Prakriti0906/water_quality_analysis/blob/main/Probabilistic_Distribution/Probalistic/Probabilistic__Distribution%20(2)%20(2).ipynb:
This file is used to calculate the probability of different models. Some of the models have in-built probabilistic output giving tendencies, and for models that do not have the  capability to give probabilistic output, the **IBUG** installation is used.
